# Linux & Bash

This section documents my practical learning journey in Linux and Bash
for bioinformatics and genomic data analysis.

## Topics

- Navigating the Linux file system
- Creating, copying, moving, and deleting files and directories
- Working with files from the command line
- Standard input, output, and redirection
- Pipes and command chaining
- Text processing with `grep`, `cut`, `sort`, `uniq`, and `awk`
- Working with biological sequence data
- Command-line analysis of genomic data

## Learning Progress

I am building these skills through hands-on exercises and bioinformatics
training, with a focus on using the Linux command line for reproducible
data analysis.
